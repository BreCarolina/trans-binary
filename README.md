# trans-binary
Pipeline completo para operações binárias com IA. Inclui transformação de dados OHLCV, modelo Transformer para previsão, política de decisão por reforço, e executor de ordens automatizado com controle de risco. Produz sistema autônomo e calibrado para operar com alta confiança.
